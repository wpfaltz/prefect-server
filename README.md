# [PT-BR] Prefect Stack

Este diretório contém a infraestrutura necessária para executar o Prefect Server
(UI + API) para o ambiente de laboratório.

Componentes:
- Prefect Server (UI/API)
- PostgreSQL (persistência de metadados)

Esta pilha é agnóstica ao ambiente e pode ser implantada em qualquer máquina com
Docker e Docker Compose.

# [ENG] Prefect Stack

This directory contains the infrastructure required to run the Prefect Server
(UI + API) for the laboratory environment.

Components:
- Prefect Server (UI/API)
- PostgreSQL (metadata persistence)

This stack is environment-agnostic and can be deployed on any machine with
Docker and Docker Compose.
